# ZelWatch / CINEPLEX

Landing page dan detail page untuk website streaming film dengan tampilan modern, berkonsep premium, dan didesain dengan HTML + CSS serta Tailwind CDN.

## Deskripsi

Proyek ini merupakan mockup UI untuk aplikasi streaming film yang menampilkan:

- hero banner film utama
- section trending movie
- genre browsing
- new releases
- detail movie page dengan layout Tailwind
- desain responsive untuk tampilan mobile dan desktop

## Teknologi yang Digunakan

- HTML5
- CSS3
- Tailwind CSS via CDN
- Font Awesome
- Google Fonts

## Struktur Project

```bash
.
├── assets/            # gambar dan aset utama landing page
├── assstsT/           # aset pendukung untuk halaman detail Tailwind
├── index.html         # halaman utama landing page
├── style.css          # styling custom untuk landing page
├── tailwind.html      # halaman detail film yang dibuat dengan Tailwind
├── README.md          # dokumentasi proyek
└── .gitignore         # konfigurasi git (jika ada di repo Anda)
```

## Cara Menjalankan

### Opsi 1: Buka Langsung
Buka file `index.html` di browser.

### Opsi 2: Gunakan Local Server
```bash
python -m http.server 8000
```

Lalu buka:

```bash
http://localhost:8000
```

## Halaman yang Tersedia

- `index.html` → landing page utama streaming movie
- `tailwind.html` → detail halaman movie dengan desain Tailwind

## Catatan

Project ini bersifat frontend mockup, jadi belum menggunakan backend, database, atau autentikasi user.
